Definition of Ready (DoR)
Para que una Historia de Usuario sea incorporada al Sprint:
Está formulada en la plantilla estándar de Scrum y cumple con los principios INVEST.
Cuenta con criterios de aceptación completos en formato Gherkin (mínimo 1 caso normal y 1
caso alternativo/crítico).
Incluye mockups o diagramas de interacción en la vista correspondiente.
Tiene asignada su estimación en Story Points y su prioridad MoSCoW.
Las dependencias técnicas están resueltas.
Definition of Done (DoD)
Para que una Historia de Usuario se considere finalizada:
Código implementado siguiendo los estándares de diseño y linters del repositorio.
Pruebas unitarias implementadas con cobertura mínima del 80%. *(Nota: Este criterio se hará efectivo una vez que se implementen las pruebas unitarias y el script test:coverage en el proyecto).*
